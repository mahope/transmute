Support

The CLI is free and unlimited, with no account and no key. This page is about the paid desktop app: buying Pro, activating it on your machines, and what to do when it refuses to work. If you only ever use the command line, you can skip all of it.

Buying Pro

Transmute Desktop Pro is a one-time purchase of 19 USD. Stripe shows the price in your own currency, and there is no subscription and nothing to cancel later. Pro lifts the limit on how many transformations the desktop app runs per launch, on up to three machines.

Buy Transmute Desktop Pro

After payment you land on a thank-you page with your licence key on it, and the same key arrives by email from orders@mahoje.dk. Card details and receipts stay with Stripe; nothing about your payment is stored here.

What Pro changes, and what it does not

  • Pro: unlimited transformations per launch in the desktop app, on three machines.
  • Pro: the app keeps the features you already paid for if the licence server is briefly unreachable.
  • Not Pro: the CLI and the engine. They stay free, unlimited and MIT licensed, with or without a key.
  • Not included: a subscription, a hosted service, or an account to create. Your data never leaves your machine either way.

If you would rather talk it through before you buy anything, write first. The same goes if you have already bought and want to discuss a refund — say so in your message and it gets looked at.

Activating your licence

  1. Open Transmute Desktop and find the licence section in its settings.
  2. Paste the key and activate. The app checks it against mahope.tools and unlocks Pro straight away.

The key is 32 hexadecimal characters. It is not case sensitive, and stray spaces and line breaks are cleaned up for you, so pasting the whole block from the email also works. The app remembers the key on the machine, so you activate once per machine rather than once per launch.

Pro stays unlocked for up to seven days after the last successful check, so a licence server having a bad afternoon cannot lock you out of software you have already paid for. The app checks again when it starts and before a run that needs the licence.

Three machines

One licence activates on three machines. A machine is counted from the moment you activate on it, and it is identified by a random installation id the app generates on first run — not by your hardware, and not by anything you have to remember.

Deactivate on a machine before you sell that computer, wipe it, or move to a new one. The slot is freed and the new machine can take it. Deactivating is immediate, and there is no limit on how often you do it.

Troubleshooting

The key is rejected

Copy it again from the thank-you page or the receipt email. A truncated paste is the usual cause, and whitespace is handled for you. A key bought for a different product is refused, and so is one that has been cancelled or has run out of time.

"This device already uses a licence"

All three slots are in use. Deactivate a machine you no longer use, then activate again — see three machines.

Pro did not unlock

Restart the app after activating. If the licence server is down, the app stays in the free tier rather than pretending to be Pro; that is deliberate, and the checks that already succeeded are still valid for the seven days described above.

The app will not start, or a transformation gives the wrong result

That is an app or engine problem, not a licence problem. Report it on GitHub with the exact input and the output you got — never with a licence key attached. The same engine runs the CLI, so a bug report is easier to reproduce there.

Keeping your key safe

Treat the key like a password: it activates three machines, so anyone holding it can spend your licence.

  • Keep it in a password manager rather than in a note on your desktop.
  • Never put it in a public issue, a chat, a screenshot or a support email. Support never asks you for a key.
  • If it does leak, deactivate it on the machines you control and report it. That is recoverable; a silent leak is not.

Contact

A person reads every message, at mahoje.dk. Order and licence questions go there as well — include the email address you paid with, and leave the licence key out of it.

Something wrong in the free CLI, or a page that overstates what it does? Open an issue. The engine is a single dependency-free file, so a report with the exact command and the output you got is genuinely useful.

Supporting the project

Transmute is built and maintained by one person in Odense. If it saved you an afternoon and you feel like saying thanks, a small donation keeps it independent. It is entirely optional, and nothing in the free tool is held back for it.
